📺 Sobre o projeto

O CDNPLAY XTREAM SERVER é uma versão aprimorada do Xtream Server, desenvolvida com a proposta de trazer novos recursos e melhorias para o gerenciamento de conteúdo audiovisual.

O projeto busca oferecer uma experiência mais moderna para administrar canais, filmes e séries, com sistemas adicionais e ferramentas voltadas à praticidade no dia a dia.

✨ Funcionalidades

Recurso	Descrição
📺 Canais	Gerenciamento de canais
🎬 Filmes	Organização e gerenciamento de filmes
🍿 Séries	Gerenciamento de séries
⚙️ Sistemas	Novos sistemas e funcionalidades
🖥️ Administração	Recursos voltados ao gerenciamento da plataforma
